# 声迹 AudioDrop

使用网页界面的本机视频音频提取软件，以 Moo0 视频到 Mp3 的转换功能为参考独立实现。使用真实 FFmpeg 处理文件；无需账号、云服务、Node.js 或 pip 安装。

## 开始使用

1. 双击项目根目录的 **start.bat**。服务在后台启动，浏览器会自动打开。
2. 拖入视频、选择文件，或添加整个文件夹。大视频建议点击 **“直接选取本机文件，免复制”**，通过系统文件窗口直接读取源文件。
3. 选择输出格式与参数。有多个音轨的文件可以单独选择轨道。
4. 点击 **开始转换**，也可以开启 **添加后自动转换**。
5. 音频自动保存到项目的 **output** 文件夹。可以试听、单独下载、打包下载，或更改输出目录。

默认地址是 **http://127.0.0.1:8765**。如果端口已占用，程序会尝试后续端口，启动脚本自动打开实际地址。重复双击 start.bat 会重新打开已有服务，不会重复启动。

关闭浏览器不会停止转换。双击 **stop.bat** 可停止本项目服务和正在处理的任务。

运行环境需要 **Python 3.10 或更高版本**，没有其他 Python 包依赖。转换引擎使用 **FFmpeg Full Build**，需要 `ffmpeg.exe` 与 `ffprobe.exe`。

从 GitHub 下载或克隆后，请从 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html) 选择 Windows Full Build，解压并把这两个程序放到项目的 `bin` 文件夹。也可以使用 PATH 中已经安装的程序，或通过 `FFMPEG_PATH` / `FFPROBE_PATH` 环境变量指定程序。具体步骤见 [引擎安装说明](bin/README.md)。

本机已有的 FFmpeg 程序可以继续使用；Git 仓库保存源码与说明，可执行程序不纳入版本控制。

## 已实现的功能

- 拖放文件、批量选择、文件夹导入；可处理 FFmpeg 能读取的视频与音频。
- Moo0 列出的 **33 种输出格式**，包括常用、无损及旧式格式。
- **原始音轨 / 无损复制 / 自动格式**：复制编码后的音频数据，不重新编码。AAC 自动保存为 M4A，MP3 保存为 MP3，其他编码自动匹配容器；必要时使用 MKA 保留原编码。
- 采样率、单声道 / 立体声 / 多声道、位深、码率、0–300% 音量。
- 设置一致且目标容器兼容时可优先直接复制；显式调整参数时执行编码。
- 多音轨选择，显示编码、时长、采样率、声道与文件大小。
- 顺序转换队列、实际转换进度、逐项取消、批量取消、失败重试、再次转换。
- 可配置输出目录，自动给同名文件编号，避免覆盖已有文件。
- 单个音频下载、ZIP 批量下载；下载与试听支持 HTTP Range。
- 转换记录与输出位置持久保存，浏览器重新打开或服务重启后仍可查看。
- 网页试听；不适合浏览器直接播放的格式会生成最多 60 秒的 MP3 试听版本。
- 原始 PCM 同时生成 JSON 参数说明；ZIP 下载包含说明文件。
- 中文 / 英文切换，参数保存，Chrome / Edge 迷你悬浮窗，以及紧凑视图。

## 33 种输出格式

| 分类 | 格式 |
| --- | --- |
| 常用 | AAC、M4A (AAC)、MP3、OGG (Vorbis) |
| 无损 | AIFF、FLAC、M4A (ALAC)、OGG (FLAC)、WAV (PCM) |
| 更多与旧式 | 3GP (AMR)、3GP (AAC)、3G2 (AMR)、3G2 (AAC)、AC3、AMR、AU (PCM)、AU (A-law)、AU (μ-law)、MMF、MOV、MP2、MP4 (AAC)、RA、RM、WAV (ADPCM IMA)、WAV (ADPCM Microsoft)、WAV (ADPCM Yamaha)、WAV (GSM)、WMA、PCM (Little-Endian)、PCM (Big-Endian)、PCM (A-law)、PCM (μ-law) |

旧式格式按编码规范限制采样率、声道和码率，界面会显示适用参数。AMR-NB、3GP/3G2 AMR、WAV GSM 为 8 kHz 单声道；RA/RM 使用 RealAudio 1.0。WAV PCM 支持 16 / 24 / 32 位整数和 32 位浮点。原始 PCM 没有文件头，播放时需要配套 JSON 中的采样率与声道参数。

“无损格式”保存解码后的音频；把有损 AAC/MP3 转成 WAV 无法恢复原先压缩丢失的信息。希望保留原编码音质时，请使用“原始音轨”。

## 浏览器与本机功能

标准浏览器无法读取拖放文件的完整本机路径，拖放与网页文件选择会把数据流式复制到本机临时目录，内存不会随整个文件大小增加。**直接选取本机文件**使用系统窗口，直接读取原文件，适合大文件。

迷你悬浮窗使用浏览器的 Document Picture-in-Picture 能力。支持的 Chrome / Edge 可以在其他窗口上方显示；不支持此能力的浏览器切换到紧凑界面。网页没有直接控制整个浏览器窗口置顶的权限。

服务只监听 `127.0.0.1`。转换过程中无需互联网。接口检查 Host、Origin 和会话令牌；不接受网页指定的任意本机输入路径，直接读取的文件必须经过系统文件窗口选择。

## 数据位置

| 目录 | 内容 |
| --- | --- |
| `web/` | HTML、CSS、JavaScript 网页前端 |
| `server.py` | 本机 HTTP 服务、FFmpeg 执行、文件处理、转换队列 |
| `formats.py` | 33 种格式配置与参数校验 |
| `bin/` | FFmpeg 与 FFprobe |
| `output/` | 默认输出音频 |
| `.runtime/` | 本机临时源文件、试听缓存、转换记录、服务日志 |

**清除已结束**会清除转换记录、对应试听缓存和不再使用的临时源文件，保留输出音频。被直接选取的原视频永远不会因为清除记录而删除。服务意外停止后，未完成任务标为已取消；重新添加或重试即可。

## 开发运行

```powershell
python server.py
python server.py --no-browser --port 8765
node --check web/app.js
```

第三方引擎来源与文档见 [THIRD_PARTY.md](THIRD_PARTY.md)。
